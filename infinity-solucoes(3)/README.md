# LAF Sites Personalizados

quero que você crie um site para demonstar os layouts de sites que eu esotu fazendo. o cliente vai entrar, na pagina inicial (LAF - Soluções Empresarias) e selecionar entre duas opções (Perfil Individual e Perfil Corporativo). se ele selecionar perfil individual, crie um modelo de site no estilo do @project:3ccecd2c-ee9b-4e80-b745-c9332b269619:"Profdrleonardo" .  ele deve ter a msm estrutura, mude apenas as fotos, textos e links para ser parametrizado e unico para cada cliente, com as informacoes que ele escolher. 
se ele escolher perfil corporativo, faça um modelo na mesma estrutura do @project:9ca3eb9b-2410-4a19-b706-f65e778bfb83:"Sorriso Sao Jose Birigui" . mude apenas os nomes e fotos para ficar parametrizado e unico para cada cliente, com as informações que ele escolher. 
coloque coisas como Sua empresa, Seu Nome, Suas formações, etc.
Para a paleta de cor, pegue as dicas do .txt e veja oq se encaixa na psicologia das cores para meu projeto.
